## 🌐 Introduction to Web Application

A **Web Application** is software that runs on a web server and is accessed using a web browser over the Internet. Unlike desktop applications, users do not need to install it on their computer.

### Example

- Gmail
- Amazon
- Instagram
- Facebook
- Netflix

**Example:**

When you open **Amazon** in Chrome, search for a product, add it to your cart, and place an order, you are using a web application.

> **Key Point:** A web application runs in a browser and allows users to interact with data.
> 

---

# 💻 What is a Web Application?

A **Web Application** is a software program that works inside a web browser. It processes user requests, stores data in a database, and displays the required information.

### Example

Suppose you log in to **Gmail**.

1. Enter your email and password.
2. Gmail verifies your details.
3. If correct, it opens your inbox.

This process is handled by a web application.

---

# 🌍 Website vs Web Application

| Website | Web Application |
| --- | --- |
| Displays information | Allows users to perform actions |
| Mostly static | Dynamic |
| Login usually not required | Login often required |
| Limited interaction | High user interaction |
| Example: Company Website | Example: Amazon |

### Example

**Website:** A college website where you only read information.

**Web Application:** A college portal where you log in, check attendance, marks, and download assignments.

---

# 📱 Types of Web Applications

## 1. Static Web Application

A static web application shows the same content to every user. The information does not change unless the developer updates it.

**Example:** Portfolio website, company profile.

---

## 2. Dynamic Web Application

A dynamic web application changes content based on the user or database.

**Example:** Facebook, Instagram, Amazon.

---

## 3. E-Commerce Web Application

Used for buying and selling products online.

**Features**

- Product search
- Shopping cart
- Online payment
- Order tracking

**Example:** Amazon, Flipkart, Meesho.

---

## 4. Portal Web Application

Provides services for a specific group of users.

**Example**

- Student Portal
- Employee Portal
- Hospital Portal

---

## 5. Progressive Web Application (PWA)

A website that behaves like a mobile app. It can be installed and sometimes works offline.

**Example:** Twitter Lite.

# 📝 Chapter Summary

- A web application is software that runs in a web browser.
- It allows users to interact with data.
- Websites mainly provide information, while web applications perform tasks.
- Different types of web applications include static, dynamic, e-commerce, portal, and PWA.
