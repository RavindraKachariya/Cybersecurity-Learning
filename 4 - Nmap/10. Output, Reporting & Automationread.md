# 10. Output, Reporting & Automationread

---

## **Output Options –**

By default, Nmap shows scan results directly on the screen.

However, in real-world scanning, this is often **not enough**.

Nmap provides multiple output options so that you can:

- Save scan results for **later analysis**
- Compare results from **multiple scans**
- Process scan data using **other tools or scripts**

You can save Nmap output in:

- Plain text files
- XML files
- Grepable (search-friendly) format
- Or all formats at once

This is especially useful when:

- Scanning a large number of systems
- Running long scans
- Comparing two scans using tools like **ndiff**

---

### **Important Note (About grep)**

- The `grep` utility is available by default on **Linux, Unix, and macOS** systems.
- Windows users need to install a separate GNU grep tool to use grep-based examples.
- Grep is commonly used to **quickly search specific information** inside large scan results.

---

## **Save Output to a Text File (`oN`)**

### **What this option does**

- The `oN` option saves scan results in a **normal, readable text file**.
- The output looks almost the same as what you see on the screen.
- This format is best for **manual review and reports**.

### **Command**

```bash
nmap -oN scan.txt 10.10.1.1

```

### **What happens**

- Nmap runs the scan normally.
- All results are written into `scan.txt`.
- You can open this file anytime to review the scan.

### **Important Note**

- If the file already exists, Nmap will **overwrite it**.
- To keep old data, you must use `-append-output` along with `oN`.

---

## **Save Output to an XML File (`oX`)**

### **What this option does**

- The `oX` option saves scan results in **XML format**.
- XML output is mainly used for:
    - Automation
    - Parsing with scripts
    - Importing into other tools

### **Command**

```bash
nmap -oX scan.xml 10.10.1.1
```

### **What happens**

- Nmap creates a structured XML file.
- This file contains detailed scan data in machine-readable form.

### **Important Notes**

- XML files may reference **local stylesheet paths** that work only on the system where the scan was created.
- To make the XML portable:
    - Use `-webxml` for online stylesheet access
    - Use `-stylesheet` to specify a custom stylesheet
    - Use `-no-stylesheet` if you want raw XML only

---

## **Grepable Output (`oG`)**

### **What this option does**

- The `oG` option creates **grep-friendly output**.
- The format is optimized for searching using tools like `grep`, `awk`, or Perl.
- This is very useful when working with **large scans**.

### **Command**

```bash
nmap -oG scan.txt -F -O 10.10.1.1/24
```

### **Why this is useful**

- You can quickly search for:
    - Specific operating systems
    - Open ports
    - Specific services
- Instead of reading the whole file, you can extract only what you need.

### **Example Usage**

```bash
grep"Windows 98" scan.txt
```

This command searches the scan file and shows **only lines matching “Windows 98”**.

---

## **Output All Supported File Types (`oA`)**

### **What this option does**

- The `oA` option saves scan output in **all major formats at once**.
- It creates:
    - Plain text output
    - Grepable output
    - XML output

### **Command**

```bash
nmap -oA scans 10.10.1.1
```

### **What happens**

Nmap generates three files automatically:

- `scans.nmap` → Plain text output
- `scans.gnmap` → Grepable output
- `scans.xml` → XML output

This option is very useful when you:

- Want full flexibility later
- Are not sure which format you will need
- Are doing professional assessments

---

## **Periodically Display Scan Statistics (`-stats-every`)**

### **What this option does**

- The `-stats-every` option shows **live progress updates** during a scan.
- Nmap prints status information at regular intervals.
- This is helpful for **slow or long-running scans**.

### **Command**

```bash
nmap --stats-every 5s 10.10.1.41

```

### **What you see**

- Elapsed time
- Number of hosts completed
- Current scan phase
- Estimated time remaining

### **Why it is useful**

- Prevents confusion during long scans
- Helps you understand scan progress
- Time units can be:
    - Seconds (`s`)
    - Minutes (`m`)
    - Hours (`h`)

## **133t Output (`oS`)**

### **What this option does**

- The `oS` option enables **“1337” or script-kiddie-style output**.
- It converts normal output into stylized, cryptic text.
- This option is included **mostly as a joke**.
### **Command**

```bash
nmap -oS scan.txt 10.10.1.1
```
