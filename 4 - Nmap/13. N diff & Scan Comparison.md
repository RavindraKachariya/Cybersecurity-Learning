# 13. N diff & Scan Comparison

---

## **What is Ndiff?**

- **Ndiff** is a comparison tool that comes with the **Nmap suite**.
- It is used to **compare two Nmap scan results** and show **what changed**.
- Ndiff works only with **Nmap XML output files**.

Think of it like this:

- First scan → *Baseline*
- Second scan → *Later state*
- Ndiff answers:
    
    👉 *What is new?*
    
    👉 *What is missing?*
    
    👉 *What has changed?*
    

---

## **Why Ndiff is Important**

Ndiff is very useful when you want to:

- Track **changes in a network**
- Detect **newly opened or closed ports**
- Identify **unexpected services**
- Compare scans done at **different times**

It is commonly used in:

- Security monitoring
- Audits
- Change management
- Incident investigation

---

## **Scan Comparison Using Ndiff**

### **Command**

```bash
ndiff scan1.xml scan2.xml
```

---

## **How Ndiff Comparison Works**

- Ndiff compares **two XML scan files**
- Differences are marked using symbols:
    - (minus) → Data from the **first scan**
    - `+` (plus) → Data from the **second scan**

### **Example Meaning**

If you see:

```
-80/tcp open http
```

It means:

- Port 80 was **open in the first scan**
- But it is **not open in the second scan**

👉 This clearly shows **what changed between scans**.

---

## **Ndiff Verbose Mode (`v`)**

### **Command**

```bash
ndiff -v scan1.xml scan2.xml
```

---

## **What Verbose Mode Does**

- Shows **all scan data from both files**
- Still highlights differences using `+` and
- Unlike normal mode, it does **not hide unchanged data**

---

## **Why Verbose Mode is Useful**

- Gives **full visibility**
- Helps understand the **complete context**
- Better for **detailed analysis** and reports

👉 In most professional cases, **verbose mode is preferred**.

---

## **XML Output Mode (`-xml`)**

### **Command**

```bash
ndiff --xml scan1.xml scan2.xml
```

---

## **What XML Output Mode Does**

- Outputs Ndiff results in **XML format**
- Useful for:
    - Automation
    - Feeding data into other tools
    - Writing scripts or reports

---

## **Saving XML Output to a File**

By default, XML output is shown on screen.

To save it:

```bash
ndiff --xml scan1.xml scan2.xml > ndiff.xml
```

 This creates a file named `ndiff.xml`.

---

## **When to Use Ndiff**

- After periodic scans
- Before and after changes
- During incident response
- While monitoring network drift
