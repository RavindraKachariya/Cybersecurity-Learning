# 3. How Nmap Actually Works

# **How Nmap Actually Works.**

Before learning scan types, students must understand **how Nmap communicates with a target system** at network level.

Nmap works by **sending specially crafted packets and analyzing responses** to learn about the target.

---

## Packet Crafting & Raw Sockets

Normally, operating systems handle network packets automatically when applications communicate.

Nmap works differently:

- It **creates custom packets manually**
- Sends probes designed to trigger responses
- Observes how the target reacts

This is called **packet crafting**.

To do this, Nmap uses **raw sockets**, which allow direct packet control instead of normal application networking.

**Instructor Insight:**

Nmap doesn’t just talk to systems  it carefully designs packets to extract information.

---

## TCP Handshake Logic

Most network services use TCP, which follows a **three-step handshake**:

1. Client sends **SYN**
2. Server replies **SYN-ACK** if port open
3. Client sends **ACK**, connection established

Nmap manipulates this process:

- Sends SYN packets
- Observes responses
- Often avoids completing full connection

Responses reveal:

- Port open
- Port closed
- Port filtered

**Mental Model:**

Nmap knocks on doors and listens to the response instead of entering.

---

## Why Some Scans Need Root/Admin

Certain scans require sending **custom packets**, which needs elevated privileges.

Without admin/root access:

- OS networking stack controls packets
- Nmap cannot manipulate packets fully
- Some scan types fall back to slower methods

With root/admin:

- Nmap directly crafts packets
- Enables stealth and advanced scans

**Key Insight:**

Privileges determine how much control Nmap has over packet behavior.

---

## Latency, Retries, and Timeouts

Network communication is not instant or perfect.

Nmap handles:

- **Latency** – delay between request and response
- **Retries** – resending probes if responses missing
- **Timeouts** – deciding when no reply means filtered or dropped

High latency networks may:

- Produce slow scans
- Cause false filtered results

Nmap adjusts timing to balance:

- Speed
- Accuracy
- Reliability
