# 4. Basic Scanning Techniques

# **Scanning a Single Target with Nmap**

The simplest way to use Nmap is to scan **one host** to understand its exposed services.

Basic scan syntax:

`nmap [target]`

Target can be:

- IP address
- Hostname/domain (resolved to IP)

Example:

Scanning a local machine or server reveals which ports are reachable.

---

## What Happens in a Default Scan

When Nmap runs without extra options:

- It scans the **1000 most common TCP ports**
- Attempts to identify open services
- Determines port status
- Displays results in structured output

This gives a quick exposure overview of a system.

---

## Understanding Scan Output

Scan results usually contain columns:

### PORT

- Port number and protocol
- Example: `80/tcp`, `22/tcp`

### STATE

Shows port accessibility:

Common states:

- **Open** → Service actively accepting connections
- **Closed** → Port reachable but no service running
- **Filtered** → Firewall or filtering blocking response

Other possible states:

- Unfiltered
- Open|Filtered
- Closed|Filtered

---

### SERVICE

- Nmap guesses service running on port
- Example:
    - 80 → HTTP
    - 22 → SSH
    - 443 → HTTPS

This helps identify attack surface or available services.

---

## What This Scan Tells Us

A single host scan helps answer:

- Which ports are accessible?
- Which services are exposed?
- Is the host reachable?

It provides **initial visibility before deeper analysis**.

---

## 1️⃣ `nmap [target1 target2 ...]`

### Scan Multiple Targets

You can scan **multiple systems in one command**.

Example idea:

Scan several servers at once instead of running separate scans.

Nmap sends probes to each target and gives results one by one.

 Useful when checking:

- Multiple servers
- Several lab machines
- Company assets

**Concept:** Scan many hosts in one run.

---

## 2️⃣ `nmap [Range of IP addresses]`

### Scan IP Range

Used when IPs are sequential.

Example idea:

Scan all machines from `.1` to `.50`.

Nmap automatically scans every IP in that range.

Useful for:

- Office network discovery
- Lab subnet exploration

**Concept:** Check multiple nearby IPs quickly.

---

## 3️⃣ `nmap [Network/CIDR]`

### Scan Entire Network

CIDR notation scans a full network block.

Example idea:

Scan an entire subnet like a home or office network.

Nmap checks all possible hosts in that network.

 Useful when:

- Discovering all devices in subnet
- Internal network audits

**Concept:** Scan whole network instead of individual hosts.

---

## 4️⃣ `nmap -iL list.txt`

### Scan Targets from File

Targets stored in a file are scanned automatically.

File may contain:

- IP addresses
- Domains
- Networks

Useful when targets are large or predefined.

Useful for:

- Bug bounty scopes
- Enterprise asset lists

**Concept:** Scan targets from prepared list.

---

## 5️⃣ `nmap -iR [number]`

### Scan Random Targets

Nmap selects random IP addresses on the internet.

Example idea:

Scan random hosts globally.

Used mainly for:

- Research
- Internet exposure studies

Not recommended without purpose.

**Concept:** Random host scanning.

---

## 6️⃣ `nmap [targets] --exclude [targets]`

### Scan Except Specific Hosts

Scan network but skip certain systems.

Example idea:

Scan network but avoid scanning gateway or sensitive servers.

Useful when:

- Avoiding production servers
- Skipping critical machines

**Concept:** Scan everything except chosen systems.

---

## 7️⃣ `nmap [targets] --excludefile list.txt`

### Exclude Targets Using File

Same as exclude option but list comes from file.

Useful when many systems must be excluded.

Common in enterprise scans.

**Concept:** Skip targets from prepared exclusion list.

---

## 8️⃣ `nmap -A [target]`

### Aggressive Scan Mode

Runs multiple detection techniques automatically:

- OS detection
- Service version detection
- Script scanning
- Traceroute

Gives detailed information but:

- Slower
- Noisier

Useful for deep analysis in labs or authorized tests.

**Concept:** Full information scan.

---

## 9️⃣ `nmap -6 [target]`

### IPv6 Scanning

Used when target uses IPv6 instead of IPv4.

Modern networks increasingly use IPv6.

Without `-6`, Nmap assumes IPv4.

**Concept:** Enable IPv6 scanning.
