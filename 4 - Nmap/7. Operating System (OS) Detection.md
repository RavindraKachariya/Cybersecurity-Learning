# 7. Operating System (OS) Detection

---

## What is OS Detection?

**OS Detection** means identifying **which operating system** is running on the target system.

Examples:

- Windows
- Linux
- Ubuntu
- CentOS
- Network devices (Cisco, Router OS, etc.)

 Nmap does **not log in** to the system

 It **guesses OS** by analyzing network behavior

---

## How Nmap Detects Operating System (Simple)

Nmap:

1. Sends specially crafted packets
2. Observes TCP/IP responses
3. Checks how the system behaves
4. Matches behavior with OS fingerprint database
5. Gives the **most probable OS**

 OS detection is **probability-based**, not 100% confirmed.

---

## Basic OS Detection

### Command:

```
nmap -O [Target]
```

### What this command does:

- Sends crafted packets
- Analyzes TCP/IP stack behavior
- Matches results with Nmap OS fingerprint database
- Guesses OS type

### Used when:

- Reconnaissance
- Infrastructure pentesting
- Asset identification
- Lab demonstrations

**Concept:** Identify target operating system.

---

## OS Detection with More Details (Verbose)

### Command:

```
nmap -O -v[ Target ]
```

### Shows:

- More fingerprint details
- Matching confidence
- Extra technical information

### Good for:

- Teaching students
- Investigation
- Research walkthroughs

**Concept:** OS detection with explanation.

---

## Skip Weak OS Candidates

### Command:

```
nmap -O --osscan-limit[ Target ]
```

### What it does:

- Runs OS detection **only if**:
    - At least one open port
    - At least one closed port

### Benefits:

- Saves time
- Reduces unnecessary scans

### Best for:

- Large networks
- Automated scanning

**Concept:** Efficient OS detection.

---

## Force OS Guessing

### Command:

```
nmap -O --osscan-guess [ Target ]

```

or

```
nmap -O --fuzzy [ Target ]

```

### What it does:

- Forces Nmap to guess OS
- Works even with limited data

### Use when:

- Firewall blocks responses
- Target is heavily filtered
- Partial information available

---

## 🧪Combine OS Detection + Version Detection

### Command:

```
nmap -O -sV [ Target ]
```

### Detects:

- Operating system
- Running services
- Software versions

### Common usage:

- Recon phase
- Vulnerability assessment preparation

**Concept:** OS + service intelligence.

---

## 🚀 Aggressive Scan (Automatic OS Detection)

### Command:

```
nmap -A [ Target ]

```

### Includes:

- OS detection
- Service & version detection
- NSE scripts
- Traceroute

⚠️ Very noisy and detectable

**Concept:** One-command deep scan.

---

## 🌐 Stealth OS Detection (Professional Combo)

### Command:

```
nmap -sS -O [ Target ]

```

### Performs:

- Stealth SYN scan
- OS detection

### Used in:

- Red team operations
- Professional pentests

**Concept:** Quiet OS detection.

---

## 🔬 Debug OS Detection (Advanced / Teaching)

### Command:

```
nmap -O --packet-trace [ Target ]

```

### Shows:

- Packets sent by Nmap
- Packets received from target

### Best for:

- Deep explanation
- Packet-level analysis
- Instructor lab demo
- Forensics-style learning

**Concept:** See OS detection at packet level.

---

---

## Forensics & Reporting Combo

### Command:

```
nmap -O -sV -A--reason [ Target ]

```

### Adds:

- OS detection
- Service & version detection
- Reason field (why Nmap decided state)

### Useful for:

- Evidence explanation
- Report writing
- Defensive security audits

**Concept:** Explainable scan results.
