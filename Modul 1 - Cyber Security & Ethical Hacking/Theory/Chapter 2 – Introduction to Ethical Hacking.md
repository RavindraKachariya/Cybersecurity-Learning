# 2.1 Introduction to Ethical Hacking

## What is Ethical Hacking?

### Definition

Ethical Hacking is the process of testing the security of a computer system, network, or application with the owner's permission to find security weaknesses.

---

### Simple Explanation

Ethical Hackers use the same techniques and tools as malicious hackers, but their goal is to improve security instead of causing damage. They find vulnerabilities before attackers can exploit them.

Ethical Hacking is completely legal because it is performed with proper authorization.

---

### Real-Life Example

A bank hires an Ethical Hacker to test its online banking website. The hacker finds a security weakness and reports it to the bank so it can be fixed before criminals exploit it.

---

## Ethical Hacking vs Penetration Testing

Although both terms are similar, there is a small difference.

### Ethical Hacking

Ethical Hacking is a broad process of testing the overall security of systems, networks, and applications.

### Penetration Testing

Penetration Testing is a specific security test where authorized professionals try to exploit vulnerabilities to check how secure a system is.

### Difference

| Ethical Hacking | Penetration Testing |
| --- | --- |
| Broad security testing | Focused security testing |
| Covers overall security | Tests specific vulnerabilities |
| Continuous process | Performed for a specific assessment |

---

# 2.2 Ethical Hacking Process

Ethical Hacking follows a step-by-step process to identify and report security weaknesses.

---

## 1. Reconnaissance (Information Gathering)

### Definition

Reconnaissance is the process of collecting information about the target system before testing begins.

### Simple Explanation

The Ethical Hacker gathers details such as domain names, IP addresses, technologies, and publicly available information.

### Example

Finding the IP address and web server used by a company's website.

---

## 2. Scanning

### Definition

Scanning is the process of identifying open ports, running services, and possible vulnerabilities.

### Simple Explanation

After collecting information, the Ethical Hacker scans the target to understand which services are available and where security weaknesses may exist.

### Example

Using **Nmap** to find open ports on a server.

---

## 3. Exploitation

### Definition

Exploitation is the process of testing whether a discovered vulnerability can actually be used to gain unauthorized access.

### Simple Explanation

Ethical Hackers safely verify vulnerabilities in an authorized environment to understand their impact.

### Example

Testing whether a vulnerable login page allows unauthorized access in a controlled security assessment.

---

## 4. Reporting

### Definition

Reporting is the final step where all findings are documented and shared with the organization.

### Simple Explanation

The report includes the discovered vulnerabilities, their impact, risk level, proof of concept, and recommended solutions.

A good report helps developers fix security issues quickly.

### Example

Reporting that a website has a SQL Injection vulnerability and recommending the use of prepared statements.

---

# 2.3 Objectives of Ethical Hacking

Ethical Hacking is performed to improve security, not to damage systems.

---

## 1. Security Improvement

### Explanation

The main objective is to identify security weaknesses before attackers find them.

### Example

Fixing a vulnerable login page before it is attacked.

---

## 2. Prevent Cyber Attacks

### Explanation

Regular security testing helps organizations reduce the chances of successful cyber attacks.

### Example

Finding weak passwords before hackers do.

---

## 3. Avoid Financial Loss

### Explanation

Cyber attacks can cause huge financial losses. Ethical Hacking helps reduce these risks.

### Example

Preventing online banking fraud.

---

## 4. Maintain Customer Trust

### Explanation

Customers trust organizations that protect their personal and financial information.

### Example

An e-commerce company securing customer payment details.

---

## 5. Compliance

### Explanation

Many industries require organizations to perform security testing to meet legal and regulatory requirements.

### Example

A healthcare organization testing its systems to protect patient records.

# 2.4 Ethical Hacker

An **Ethical Hacker** is a security professional who legally tests computer systems, networks, and applications to find vulnerabilities before attackers can exploit them.

---

## Roles & Responsibilities

### 1. Identify Vulnerabilities

### Explanation

An Ethical Hacker searches for security weaknesses in systems, networks, and applications.

### Example

Finding a weak login page on a company's website.

---

### 2. Perform Security Testing

### Explanation

They perform vulnerability assessments and penetration testing to check the security of systems.

### Example

Testing whether a company's web application is secure.

---

### 3. Report Security Issues

### Explanation

After testing, they prepare a report that explains the vulnerabilities, their impact, and how to fix them.

### Example

Reporting that a server is running outdated software.

---

### 4. Improve Security

### Explanation

Ethical Hackers help organizations strengthen their security by suggesting security improvements.

### Example

Recommending Multi-Factor Authentication (MFA) for employee accounts.

---

## Skills Required

A good Ethical Hacker should have knowledge of:

- Computer Networking
- Operating Systems (Windows & Linux)
- Web Applications
- Programming Basics
- Cyber Security Concepts
- Problem Solving
- Communication Skills

---

## Legal Warning (Permission & Authorization)

### Explanation

Ethical Hacking should **always** be performed with **written permission** from the system owner.

Without authorization, testing or accessing someone else's system is illegal and may lead to legal action.

### Golden Rule

**"No Permission = No Testing."**

---

# 2.5 Types of Hackers

Hackers are classified based on their intention and authorization.

---

## 1. White Hat Hacker

### Definition

A White Hat Hacker is an authorized security professional who helps organizations improve security.

### Goal

Protect systems by finding vulnerabilities before attackers do.

### Example

A Penetration Tester hired by a company.

---

## 2. Black Hat Hacker

### Definition

A Black Hat Hacker illegally accesses systems to steal data, damage systems, or make money.

### Goal

Personal benefit or criminal activity.

### Example

Stealing customer credit card information from a website.

---

## 3. Grey Hat Hacker

### Definition

A Grey Hat Hacker accesses systems without permission but usually does not have malicious intentions.

### Goal

Find vulnerabilities and sometimes report them to the owner.

### Example

Finding a website vulnerability without permission and informing the company.

> **Note:** Even with good intentions, accessing a system without permission is still unauthorized.
> 

---

## Difference Between Hackers

| White Hat | Grey Hat | Black Hat |
| --- | --- | --- |
| Legal | Unauthorized | Illegal |
| Protects Systems | Finds Vulnerabilities | Damages Systems |
| Permission Required | No Permission | No Permission |
| Security Purpose | Mixed Intent | Criminal Intent |

---

# 2.6 Cyber Security Teams

Large organizations have different security teams to protect their systems.

---

## 1. Blue Team

### Definition

The Blue Team is responsible for defending and protecting an organization's systems.

### Responsibilities

- Monitor systems
- Detect attacks
- Apply security patches
- Respond to incidents

### Example

Blocking malware before it spreads inside the company.

---

## 2. Red Team

### Definition

The Red Team acts like real attackers and performs simulated attacks to test security.

### Responsibilities

- Find vulnerabilities
- Perform penetration testing
- Test company security

### Example

Attempting to gain access to a company's network during a security assessment.

---

## 3. Purple Team

### Definition

The Purple Team works as a bridge between the Red Team and Blue Team.

### Responsibilities

- Share knowledge
- Improve security
- Enhance detection capabilities

### Example

Helping the Blue Team learn from Red Team attack simulations.

---

## 4. SOC Team (Security Operations Center)

### Definition

The SOC Team continuously monitors the organization's systems for security threats.

### Responsibilities

- Monitor alerts
- Detect attacks
- Investigate suspicious activities
- Respond to incidents

### Example

Detecting multiple failed login attempts from a suspicious IP address.

---

## 5. Incident Response Team

### Definition

The Incident Response Team handles cyber security incidents after they occur.

### Responsibilities

- Investigate attacks
- Contain the incident
- Recover systems
- Prepare incident reports

### Example

Recovering company systems after a ransomware attack.

---

# 2.7 Important Cyber Security Terminology (Part 1)

Understanding these terms is important for exams, interviews, and practical work.

---

## 1. Virus

### Definition

A Virus is a type of malware that attaches itself to files and spreads when the infected file is executed.

### Example

An infected USB drive spreading malware to another computer.

---

## 2. Threat

### Definition

A Threat is anything that can cause harm to a system, network, or data.

### Example

Hackers, malware, or phishing attacks.

---

## 3. Risk

### Definition

Risk is the possibility that a threat may successfully exploit a vulnerability and cause damage.

### Example

Using weak passwords increases the risk of account compromise.

---

## 4. Vulnerability

### Definition

A Vulnerability is a weakness in a system that attackers may exploit.

### Example

Using outdated software with known security flaws.

---

## 5. Vulnerability Assessment (VA)

### Definition

A Vulnerability Assessment is the process of identifying and evaluating security weaknesses in a system.

### Example

Scanning a server to find outdated software or missing security patches.

---

## 6. Penetration Testing (PT)

### Definition

Penetration Testing is an authorized security test that verifies whether identified vulnerabilities can actually be exploited.

### Example

Testing whether a vulnerable login page can be bypassed in a controlled environment.

# 2.7 Important Cyber Security Terminology

---

## 7. Firewall

### Definition

A **Firewall** is a network security system that monitors and controls incoming and outgoing network traffic based on security rules.

### Simple Explanation

It acts like a **security guard**, allowing trusted traffic and blocking unauthorized or harmful traffic.

### Example

Blocking hackers from accessing a company's internal network.

---

## 8. IDS (Intrusion Detection System)

### Definition

An IDS monitors network or system activities and detects suspicious or malicious behavior.

### Simple Explanation

It only **detects attacks and sends alerts**, but it does not stop them.

### Example

Detecting multiple failed login attempts and alerting the administrator.

---

## 9. IPS (Intrusion Prevention System)

### Definition

An IPS not only detects attacks but also blocks malicious traffic automatically.

### Simple Explanation

Unlike IDS, IPS can **take action immediately** to prevent attacks.

### Example

Blocking an attacker who is trying to scan network ports.

---

## 10. IP Address

### Definition

An IP Address is a unique address assigned to every device connected to a network.

### Simple Explanation

It helps devices communicate with each other over the network.

### Example

192.168.1.10

---

## 11. Exploit

### Definition

An Exploit is a method or program used to take advantage of a security vulnerability.

### Simple Explanation

Attackers use exploits to gain unauthorized access or perform unwanted actions.

### Example

Using a software vulnerability to access a system.

---

## 12. Payload

### Definition

A Payload is the action performed after a vulnerability has been successfully exploited.

### Simple Explanation

Exploit opens the door, while the payload performs the intended action.

### Example

Opening a command shell after successful exploitation.

---

## 13. Network

### Definition

A Network is a group of two or more connected devices that communicate with each other.

### Example

A laptop, mobile phone, and printer connected to the same Wi-Fi network.

---

## 14. VPN (Virtual Private Network)

### Definition

A VPN creates a secure and encrypted connection between your device and the internet.

### Simple Explanation

It protects your online privacy and keeps your data safe, especially on public Wi-Fi.

### Example

Using a VPN while working from a coffee shop.

---

## 15. Proxy

### Definition

A Proxy Server acts as an intermediary between the user and the internet.

### Simple Explanation

Instead of connecting directly to a website, your request first goes to the proxy server.

### Example

Accessing blocked websites through a proxy server.

---

## 16. Confidentiality

### Definition

Confidentiality ensures that only authorized users can access sensitive information.

### Example

Only you can view your online banking account.

---

## 17. Integrity

### Definition

Integrity ensures that data remains accurate and is not modified without authorization.

### Example

Your bank balance should not change without your permission.

---

## 18. Availability

### Definition

Availability ensures that systems and data are accessible whenever authorized users need them.

### Example

A hospital server should be available 24×7.

---

## 19. Social Engineering

### Definition

Social Engineering is the technique of manipulating people to reveal confidential information.

### Example

A fake bank call asking for your OTP.

---

## 20. Zero-Day Vulnerability

### Definition

A Zero-Day Vulnerability is a newly discovered security flaw for which no official fix or patch is available.

### Example

Attackers exploit a software bug before the company releases an update.

---

## 21. Cryptography

### Definition

Cryptography is the process of protecting information by converting it into a secure format.

### Example

WhatsApp uses encryption to protect messages.

---

## 22. Bug Bounty

### Definition

A Bug Bounty Program rewards security researchers for responsibly reporting vulnerabilities.

### Example

Finding a security bug on a company's website and receiving a reward.

---

## 23. Hashing

### Definition

Hashing converts data into a fixed-length value that cannot be easily reversed.

### Simple Explanation

It is mainly used to verify data integrity and securely store passwords.

### Example

Websites store hashed passwords instead of plain passwords.

---

## 24. Authentication

### Definition

Authentication verifies the identity of a user.

### Example

Logging in with a username and password.

---

## 25. Authorization

### Definition

Authorization determines what resources or actions an authenticated user is allowed to access.

### Example

Only an administrator can access the admin panel.

---

## 26. CVE (Common Vulnerabilities and Exposures)

### Definition

CVE is a publicly available list of known security vulnerabilities.

### Example

A software vulnerability assigned a unique CVE ID for reference.

---

## 27. CWE (Common Weakness Enumeration)

### Definition

CWE is a list of common software security weaknesses that can lead to vulnerabilities.

### Example

Improper input validation causing SQL Injection.

---

## 28. Keylogger

### Definition

A Keylogger is software or hardware that records every key pressed on a keyboard.

### Example

Stealing usernames and passwords typed by a user.

---

## 29. Botnet

### Definition

A Botnet is a group of infected devices controlled remotely by an attacker.

### Example

Thousands of infected computers launching a DDoS attack.

---

## 30. Insider Threat

### Definition

An Insider Threat is a security risk caused by someone inside an organization.

### Example

An employee leaking confidential company data.

---

## 31. Spoofing

### Definition

Spoofing is the act of pretending to be someone or something else to gain trust.

### Example

A fake email appearing to come from your bank.

---

## 32. Sniffing

### Definition

Sniffing is the process of capturing and analyzing network traffic.

### Example

Monitoring data packets on a local network.

---

## 33. Eavesdropping

### Definition

Eavesdropping is the unauthorized interception of private communication between two parties.

### Example

An attacker listening to unencrypted network communication.

---

# 2.8 Day 2 Tool – Proxyium

## What is Proxyium?

### Definition

**Proxyium** is a free web-based proxy service that allows users to browse websites through a proxy server without installing any software.

---

### Simple Explanation

Instead of connecting directly to a website, your request first goes to Proxyium, and then Proxyium connects to the website on your behalf.

This helps hide your real IP address and access websites that may be blocked.

---

### Example

If a website is blocked on your network, you can open it through Proxyium without directly connecting to that website.

---

## Uses of Proxyium

### 1. Hide Your IP Address

Your real IP address is hidden from the destination website.

**Example:** Browsing a website without revealing your original IP.

---

### 2. Access Blocked Websites

Some websites may be restricted in schools or offices.

A proxy helps access those websites.

---

### 3. Improve Privacy

The website receives the proxy server's IP instead of yours.

---

### 4. No Installation Required

Proxyium works directly in your web browser.

---

## Proxy vs VPN

| Proxy | VPN |
| --- | --- |
| Protects only browser traffic | Protects all internet traffic |
| Faster | Slightly slower due to encryption |
| Basic privacy | Strong privacy & security |
| Usually no encryption | Encrypts all data |
| Easy to use | Requires installation |

### Easy Trick

**Proxy = Browser Protection**

**VPN = Full Device Protection**

# 2.9 Ethical Hacking vs Cyber Security

Although both are related, they are different concepts.

## Ethical Hacking

### Explanation

Ethical Hacking focuses on finding security vulnerabilities by performing authorized security testing.

### Goal

Find weaknesses before attackers do.

---

## Cyber Security

### Explanation

Cyber Security is the overall process of protecting computers, networks, applications, and data from cyber attacks.

### Goal

Prevent attacks and secure digital systems.

---

## Difference

| Ethical Hacking | Cyber Security |
| --- | --- |
| Finds vulnerabilities | Protects systems |
| Offensive security | Defensive security |
| Performs security testing | Implements security controls |
| Part of Cyber Security | Complete security field |
