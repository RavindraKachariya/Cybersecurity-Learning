# 8.1 Introduction to Operating System (OS)

## What is an Operating System?

An **Operating System (OS)** is system software that manages computer hardware and software resources and provides an interface between the user and the machine.

The OS controls:

- CPU
- Memory
- Storage
- Applications
- Network devices

**Examples:**

- Windows
- Linux
- macOS
- Android

**Example:**

When a user opens a browser, the operating system manages the required memory, processor usage, and network connection.

---

# Functions of an Operating System

## 1. Process Management

Manages running applications and allocates CPU resources.

Example:

Running Chrome, music player, and other applications together.

---

## 2. Memory Management

Controls how RAM is used by different programs.

Example:

Giving required memory to applications.

---

## 3. File Management

Manages files and directories.

Functions:

- Create files
- Delete files
- Store data

---

## 4. Device Management

Controls hardware devices.

Examples:

- Keyboard
- Mouse
- Printer
- Network devices

---

## 5. Security Management

Provides security features:

- User accounts
- Permissions
- Authentication

---

## 6. Network Management

Controls network communication.

Example:

Connecting to internet or local networks.

---

# Importance of an Operating System

An OS is important because it:

- Makes computer usage easier.
- Provides a platform to run applications.
- Manages hardware resources.
- Provides security.
- Improves system performance.

# 8.8 Real-World Security Assessment Workflow

A professional security assessment follows a structured process.

---

# 1. Information Gathering (OSINT)

Collect public information about the target.

Examples:

- Domain details
- Email addresses
- Technologies used

Tools:

- Maltego
- theHarvester

---

# 2. Network Discovery (Nmap)

Identify:

- Active hosts
- Open ports
- Services

---

# 3. Traffic Analysis (Wireshark)

Analyze network communication.

Purpose:

- Detect suspicious traffic
- Understand protocols

---

# 4. Vulnerability Scanning (Nessus)

Find:

- Vulnerabilities
- Misconfigurations
- Missing patches

---

# 5. Security Validation

Verify identified security issues.

Tools:

- Metasploit
- Burp Suite

---

# 6. Reporting

Document:

- Findings
- Risk level
- Evidence
- Recommendations

---

# 7. Remediation

Fix identified vulnerabilities.

Examples:

- Apply patches
- Update software
- Improve security controls
